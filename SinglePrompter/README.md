# 싱글 프롬프터

한국어 대본을 읽는 음성을 듣고, 현재 문장을 강조하며 자동 스크롤하는 Android 앱의 첫 버전입니다.

## 실행

Android Studio Hedgehog 이상에서 이 폴더를 열고 Gradle 동기화 후 실행하세요. 기기에서 **마이크 권한**을 허용해야 합니다. 첫 실행 때 Android 시스템 음성 인식 서비스를 사용할 수 있는 인터넷 연결이 필요할 수 있습니다.

## 사용법

1. 대본을 작성하거나 붙여넣습니다. 줄 또는 문단 하나가 한 프롬프터 단위가 됩니다.
2. `프롬프터 시작`을 누르고 마이크 버튼을 누릅니다.
3. 현재·다음 네 줄 범위에서 인식된 단어와 가장 유사한 줄을 찾아 표시합니다.
4. 인식이 빗나갈 때는 이전/다음 버튼으로 즉시 보정합니다.

## 현재 범위와 다음 단계

- 한국어 Android 시스템 음성 인식을 사용합니다. 기기·네트워크 상태에 따라 정확도가 달라질 수 있습니다.
- 대본 파일 불러오기, 대본 저장, 글자 크기 조절, 가로 프롬프터/미러 모드, 오프라인 Whisper 인식은 다음 버전에 추가하기 좋은 기능입니다.
